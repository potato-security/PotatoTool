# 漏洞扫描模块优化计划

## 一、问题分析汇总

### 1. 性能问题：UI触发扫描比测试慢
**问题原因**：
- `UnifiedVulnScanService.scan()` 是串行逐目标扫描（第77行 for 循环）
- 每个目标内的 POC 也是串行执行的（第183行），只有启用聚类时才使用 `ClusteredPocExecutor`
- 与测试代码可能直接使用 `ScanEngine` 并行执行不同

**相关代码**：
- `UnifiedVulnScanService.java:77-88` - 串行遍历目标
- `UnifiedVulnScanService.java:182-227` - 串行执行 POC

### 2. 进度条和进度不动
**问题原因**：
- `handleUnifiedScanEvent()` 中进度解析逻辑存在问题（PaneVulScan.java 第333-346行）
- 解析格式 `"进度: X/Y"` 但实际消息格式是 `"进度: X/Y (Z%)"`
- `UnifiedVulnScanService` 只在每完成 10 个 POC 时报告一次进度（第219-225行）
- 目标级别的进度没有反馈

**相关代码**：
- `PaneVulScan.java:331-347` - 进度事件处理
- `UnifiedVulnScanService.java:219-225` - 进度报告

### 3. UI触发流程与设计不一致
**问题**：
- 当前 `startScanTask()` 使用 `UnifiedVulnScanService` 而不是 `VulnScanService/ScanEngine`
- `UnifiedVulnScanService` 是串行的，没有使用线程池并发执行
- 与 CLAUDE.md 中描述的 `ScanEngine` 多线程架构不一致

**设计预期**：
```
VulnScanService → ScanEngine (ThreadPoolExecutor) → PocExecutor
```

**实际流程**：
```
UnifiedVulnScanService (串行) → PocExecutor
```

### 4. OSINT 等特殊目录 POC 问题
**问题**：
- `ScanConfig` 默认已排除 OSINT、TOKEN_SPRAY、CREDENTIAL_STUFFING（第61-65行）
- `UnifiedVulnScanService.selectPocs()` 中第315-318行跳过 `requiresSpecialInput()` 的 POC
- 用户无法通过 UI 选择是否包含这些特殊 POC

**相关代码**：
- `ScanConfig.java:61-65` - 默认排除配置
- `UnifiedVulnScanService.java:314-318` - 智能模式跳过特殊 POC

### 5. 停止扫描无效
**问题原因**：
- `UnifiedVulnScanService.cancel()` 只设置 `cancelled=true`
- 虽然在第77行和第184行检查 `cancelled`，但 POC 执行期间无法响应
- `stopScan()` 调用了 `currentTask.cancel()` 和 `currentThread.interrupt()`，但 POC 执行是阻塞的

**相关代码**：
- `PaneVulScan.java:974-992` - 停止扫描方法
- `UnifiedVulnScanService.java:417-419` - cancel 方法

### 6. UI 简化需求
**需要移除**：
- 预设按钮（快速/标准/深度） - FXML 第94-103行
- 等级筛选（Critical/High/Medium/Low/Info） - FXML 第113-129行
- 指纹识别、POC去重、响应缓存、请求聚类配置项 - FXML 第150-154行

**需要保留但隐藏为默认值**：
- 请求聚类：默认启用
- 响应缓存：默认启用
- POC去重：默认启用

### 7. 设置模块整合
**需要移动到设置模块**：
- 线程并发数（threadsField）
- 超时时间（timeoutField）
- 重试次数（retriesField）

### 8. POC 仓库管理问题
**问题 a：POC 计数显示 0**
- `updatePocCountLabel()` 在过滤器初始未设置时不更新

**问题 b：批量操作无效**
- `enableAllPocs()` 和 `disableAllPocs()` 只更新了内存中的 `PocItem`
- 没有同步到数据库 `PocDatabaseManager.setEnabled()`

**问题 c：缺少批量导出**
- 需要添加批量导出功能

**相关代码**：
- `PaneVulScan.java:2089-2105` - 批量启用/禁用

### 9. 暂停功能问题
**问题**：
- `pauseScan()` 方法检测到使用 `UnifiedVulnScanService` 时直接返回"不支持暂停"
- `UnifiedVulnScanService` 没有实现暂停机制（保存状态、恢复状态）

**相关代码**：
- `PaneVulScan.java:951-963` - 暂停扫描方法

## 二、优化方案

### 阶段一：核心架构修复

#### 1.1 重构扫描执行流程
**目标**：使用 `ScanEngine` 替代 `UnifiedVulnScanService` 的串行执行

**修改内容**：
- 将 `UnifiedVulnScanService` 的智能筛选逻辑（指纹识别、去重、分类筛选）提取为独立工具类
- 让 `startScanTask()` 使用 `VulnScanService/ScanEngine` 进行并发扫描
- 保留 `UnifiedVulnScanService` 的 POC 选择逻辑作为预处理

**新流程**：
```
1. UI 构建配置 → ScanConfig
2. UnifiedVulnScanService.selectPocs() → 筛选 POC 列表
3. ScanEngine.startScan(targets, filteredPocs) → 多线程执行
4. 事件回调 → UI 更新
```

#### 1.2 修复进度更新机制
**修改内容**：
- `ScanEngine` 已有完善的进度事件机制，需要正确注册监听器
- 修改 `handleUnifiedScanEvent()` 中的进度解析逻辑
- 添加目标级别的进度反馈

#### 1.3 修复停止/暂停功能
**修改内容**：
- 使用 `ScanEngine.stopScan()` 和 `ScanEngine.pauseScan()`
- 添加 `ExecutorService.shutdownNow()` 强制终止
- 实现 `InterruptiblePocExecutor` 支持中断

## 五、关键代码修改示例

### 5.1 修复 startScanTask 使用 ScanEngine

```java
private void startScanTask(List<String> targets) {
    ScanConfig config = buildScanConfig();

    // 1. 使用 UnifiedVulnScanService 预筛选 POC
    List<PocObj.Poc> selectedPocs = selectPocsForScan(targets.get(0), config);

    if (selectedPocs.isEmpty()) {
        showPrompt("没有找到匹配的 POC", true);
        return;
    }

    // 2. 注册事件监听器
    scanService.addEventListener(new ScanEventAdapter() {
        @Override
        public void onScanProgress(ScanProgressEvent event) {
            Platform.runLater(() -> {
                double progress = event.getProgress();
                progressBar.setProgress(progress);
                progressLabel.setText(String.format("%.1f%%", progress * 100));
            });
        }

        @Override
        public void onVulnerabilityFound(VulnerabilityFoundEvent event) {
            Platform.runLater(() -> {
                scanResults.add(event.getResult());
                addVulnResultToUI(event.getResult());
            });
        }

        @Override
        public void onScanCompleted(ScanCompletedEvent event) {
            Platform.runLater(() -> {
                resetScanButtons();
                updateStatistics(scanResults);
                updateScanStateLabel("已完成");
            });
        }
    });

    // 3. 设置 POC 并启动扫描
    scanService.setPocs(selectedPocs);
    for (String target : targets) {
        scanService.addTarget(target);
    }

    // 4. 异步启动
    currentTask = new Task<Void>() {
        @Override
        protected Void call() {
            scanService.startScan();
            return null;
        }
    };

    currentThread = new Thread(currentTask);
    currentThread.setDaemon(true);
    currentThread.start();
}
```

### 5.2 修复批量操作

```java
@FXML
public void enableAllPocs(ActionEvent event) {
    ObservableList<PocItem> selectedItems = pocTableView.getSelectionModel().getSelectedItems();
    if (selectedItems.isEmpty()) {
        // 如果没有选中，则操作全部
        selectedItems = allPocItems;
    }

    PocDatabaseManager dbManager = PocDatabaseManager.getInstance();
    List<String> ids = new ArrayList<>();

    for (PocItem item : selectedItems) {
        item.setEnabled(true);
        ids.add(item.getId());
    }

    // 批量更新数据库
    new Thread(() -> {
        dbManager.batchSetEnabled(ids, true);
        Platform.runLater(() -> {
            pocTableView.refresh();
            showPrompt("已启用 " + ids.size() + " 个POC", false);
        });
    }).start();
}
```

### 5.3 添加批量导出

```java
@FXML
public void exportSelectedPocs(ActionEvent event) {
    ObservableList<PocItem> selectedItems = pocTableView.getSelectionModel().getSelectedItems();
    if (selectedItems.isEmpty()) {
        showPrompt("请先选择要导出的POC", true);
        return;
    }

    DirectoryChooser chooser = new DirectoryChooser();
    chooser.setTitle("选择导出目录");
    File dir = chooser.showDialog(getStage());

    if (dir == null) return;

    new Thread(() -> {
        PocDatabaseManager dbManager = PocDatabaseManager.getInstance();
        int success = 0, failed = 0;

        for (PocItem item : selectedItems) {
            try {
                PocDatabaseManager.PocEntity entity = dbManager.getPocById(item.getId());
                if (entity != null && entity.getOriginalContent() != null) {
                    String filename = entity.getOriginalFilename();
                    if (filename == null) filename = item.getId() + ".yaml";

                    File outFile = new File(dir, filename);
                    Files.write(outFile.toPath(),
                        entity.getOriginalContent().getBytes(StandardCharsets.UTF_8));
                    success++;
                }
            } catch (Exception e) {
                failed++;
            }
        }

        int finalSuccess = success;
        int finalFailed = failed;
        Platform.runLater(() ->
            showPrompt(String.format("导出完成: 成功 %d, 失败 %d", finalSuccess, finalFailed), false));
    }).start();
}
```
